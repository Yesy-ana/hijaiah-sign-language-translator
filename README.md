# Hijaiah Sign Language Translator

Android application for learning Hijaiah sign language through interactive visual learning features for the deaf community.

## Features
- Letter Learning with sign-language videos
- Letter Matching using drag-and-drop interactions
- Interactive Quizzes for learning evaluation

## Technologies
- Java
- Android Studio
- XML

## Development Method
- Waterfall Method
- Black-box Testing
- System Usability Scale (SUS)

## Purpose
This application was developed to support adaptive and disability-friendly Islamic education for deaf users.
